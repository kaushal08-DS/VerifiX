# Fraud Detection System

Machine Learning based Fraud Detection System built using:

- Python
- Scikit-Learn
- Random Forest
- SMOTE
- Streamlit

## Features

- Fraud Prediction
- Fraud Probability Score
- CSV Upload
- Download Results
- Fraud Analytics Dashboard

## Model Performance

- Accuracy: 99.95%
- Precision: 87%
- Recall: 83%
- F1 Score: 85%

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
